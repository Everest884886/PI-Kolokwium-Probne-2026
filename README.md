# Kolokwium próbne — diagnostyka logów 2026

**Podstawy informatyki — Nanoinżynieria Materiałów, AGH WFiIS.**

Repozytorium startowe do praktycznego kolokwium (45 minut, 10 punktów).

> Materiał do ćwiczeń: dane i opisy są fikcyjne. Nie umieszczaj tutaj haseł, kluczy prywatnych ani danych osobowych.

## Szybki start

```bash
ls -lah
head -n 3 dane/proba_A.log
bash -n src/analiza.sh
```

**Przeczytaj [`ZADANIA.md`](ZADANIA.md).** Zmieniaj pliki wyłącznie we własnym forku repozytorium.
